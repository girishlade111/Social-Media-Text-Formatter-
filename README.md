# Social Media Text Formatter

**Built by [Girish Lade](https://ladestack.in)**

A free, no-login, client-side text formatter for WhatsApp and social media. Type or paste text, apply formatting styles, preview instantly, and copy with one click — everything runs in your browser, nothing is uploaded anywhere.

## ✨ Features

- **WhatsApp formatting** — bold, italic, strikethrough, monospace via WhatsApp markup
- **Unicode styles** — fancy unicode text variants (𝖻𝗈𝗅𝖽, 𝑖𝑡𝑎𝑙𝑖𝑐, etc.) for Instagram, X, Facebook
- **Live preview** — see the formatted result as you type
- **One-click copy** — copy formatted text straight to clipboard
- **Dark mode** — light/dark theme toggle
- **100% client-side** — single HTML file, zero dependencies, works offline

## 🛠️ Tech Stack

- Plain **HTML5**, **CSS3** (custom properties), vanilla **JavaScript**
- No frameworks, no build step, no dependencies

## 🚀 Quick Start

Just open `index.html` in any browser — no install, no server needed:

```bash
git clone https://github.com/girishlade111/Social-Media-Text-Formatter-.git
cd Social-Media-Text-Formatter-
# open index.html in your browser
```

Or serve locally:

```bash
npx serve .
```
